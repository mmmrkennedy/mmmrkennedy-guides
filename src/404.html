Without it, Pages answers unknown paths with index.html and a 200, and because src/_headers matches on path, a miss on /js/[hash].js got stamped `public, max-age=2592000`: an edge node that briefly lacked a newly-deployed asset cached that HTML under the asset's URL for 30 days, and the site's JS was dead until someone purged the cache by hand. This file makes that a 404. It uses base.njk like every other page. The trade-off: if the CSS bundle is itself what's missing mid-deploy, this page renders unstyled for that window. It still returns 404, so the caching fix above is unaffected. `notFoundPage` (base.njk) makes it noindex, drops canonical and JSON-LD, and keeps the view counter and reading analytics from logging every mistyped URL. -#}
